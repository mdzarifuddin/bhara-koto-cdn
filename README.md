# bhara-koto-cdn

Encrypted (AES-256-GCM) and signed (Ed25519) data snapshots for the **ভাড়া কত / Vara Koto** app.
The files are useless without the app. Each release is an immutable tag `<dataset>-v<N>`; `manifest.json` lists the current versions.
Published automatically by the private data repo's GitHub Actions workflow.
